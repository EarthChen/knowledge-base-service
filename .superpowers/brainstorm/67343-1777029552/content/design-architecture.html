📥 数据管道（索引时）

↓ 存入 FalkorDB
FalkorDB

ImportanceScorer [新增]
百分位排名 → core / standard / skeleton
SourceCodeReader [新增]
file/line → 精准代码
ChunkRetriever [新增]
向量检索 → 相关代码
↓ 合并到
EnrichedContextAssembler [新增]
图谱结构 + 精准代码 + 语义代码 + 文档 → 统一 Context
↓ 送入
TieredComposer [增强 WikiComposer]
根据 importance_tier 选择生成策略：
• core → 百科模式（多层 LLM）
• standard → 标准模式（单次 LLM）
• skeleton → 骨架模式（模板，无 LLM）
↓ 输出

核心原则
  • 不替换现有组件 — 所有新增组件通过接口组合到现有 WikiService 中
  • 向后兼容 — mode=structure 和现有 API 行为不变
  • 渐进交付 — Phase 1/2/3 独立可用，无相互依赖
