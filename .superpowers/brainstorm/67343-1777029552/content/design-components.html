🟢 Phase 1: 代码感知层

SourceCodeReader — 精准代码读取
输入: GraphNode (file, start_line, end_line) + Chunk 节点 (text, parent_uid)
输出: CodeSnippet(source, file_path, start_line, end_line, context_lines)

策略（优先级递减）:
  1. Chunk.text — 如果目标节点有关联的 CHUNK 子节点，直接使用 text 属性（最快，零 IO）
  2. 文件读取 — 用 file + start_line/end_line 从仓库路径读取（需配置 repo_base_path）
  3. 降级为签名 — 如果文件不可访问，退回使用 signature + docstring（现有行为）
Token 预算控制:
  • 核心实体: 最多 8000 tokens 代码
  • 普通实体: 最多 3000 tokens 代码
  • 骨架实体: 仅签名，~500 tokens
  • 超长函数自动截断，保留首尾 + 关键逻辑标注
ImportanceScorer — 实体重要度评分
评分公式: 
score = (in_degree × 3) + (out_degree × 1) + (children_count × 2) + log2(code_lines + 1) × 2

# 附加权重
if label == MODULE:  score += 5
if label == CLASS and has_subclasses: score += 3
分层（百分位）:
  • core (Top 20%) — 百科模式，多层 LLM
  • standard (中间 50%) — 标准模式，单次 LLM
  • skeleton (底部 30%) — 模板骨架，无 LLM
增强 WikiDataCollector — PageData 扩展
PageData 新增字段: 
@dataclass
class PageData:
    # ... 现有字段 ...
    code_snippets: list[CodeSnippet]   # [新增] 精准代码片段
    importance_tier: ImportanceTier     # [新增] core/standard/skeleton
    related_chunks: list[ChunkSnippet] # [Phase2 新增] RAG 检索结果

🔵 Phase 2: RAG 检索层

CodeChunkIndexer — 批量 Embedding 生成
任务: 为现有 67K Chunk 节点的 text 属性生成 embedding
执行方式: 批量任务，独立于 wiki 生成流程
进度: 写入 Chunk.embedding 属性，利用已有 VECTOR INDEX

性能估算:
  • 67,627 chunks × 平均 733 bytes ≈ 50MB 文本
  • 批量处理 (batch=64): ~20分钟（取决于 embedding 模型速度）
  • 可中断续跑: 跳过已有 embedding 的节点
ChunkRetriever — 语义检索
输入: 实体名/FQN/描述 → embedding
检索: vector_search(CHUNK, embedding, k=10, repository=...)
过滤: 去除已在 code_snippets 中的精准代码（去重）
输出: 最多 5 个语义相关代码片段

检索策略（按实体类型）:
  • MODULE: 用模块名 + 描述检索 → 找到跨文件相关逻辑
  • CLASS: 用类名 + 方法签名检索 → 找到使用示例和调用方
  • FUNCTION: 用函数名 + docstring 检索 → 找到相关函数和测试

🟣 Phase 3: 百科分层生成

BusinessDomainPlanner — 业务领域识别
任务: 在生成目录前，先用 LLM 识别项目的业务领域
输入: 顶层模块列表 + 各模块简要信息
输出: 业务领域树（如: 用户管理 → 订单处理 → 支付流程）
映射: 每个业务领域关联到 1-N 个代码模块

文档结构（混合模式）: 
📖 项目概览
├── 📂 用户管理（业务领域）         ← LLM 识别
│   ├── 📄 领域概述                  ← 跨模块业务流程
│   ├── 📦 user-service/             ← 代码模块（下钻）
│   │   ├── UserController           ← core 实体 → 百科
│   │   ├── UserService              ← core 实体 → 百科
│   │   └── UserDTO                  ← skeleton 实体 → 骨架
│   └── 📦 auth-module/
├── 📂 订单处理（业务领域）
└── 📂 基础设施（技术通用）          ← 非业务模块归类
